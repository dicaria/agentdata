# Contributing

Thanks for your interest in improving agentdata.

## The short version

This repository is a release mirror: the SDK and its contract docs are
published here from the project's development line, and the public history is
rebuilt from that line. So:

- **Issues are welcome and read.** Bug reports, wrong upstream parameters,
  rate-limit facts that no longer match reality, and data-coverage requests
  are all useful.
- **Pull requests are not the primary contribution path.** Because the public
  tree is generated from the development line, most PRs cannot be merged
  as-is. If you want to change code, open an issue first describing the
  proposed change; small, self-contained fixes may be folded in.

## What makes a good issue

1. The command you ran, e.g. `agentdata <domain> <source>_<dataset> ...`
2. The JSON envelope returned (or the full traceback)
3. The date, and if relevant the upstream's own response
